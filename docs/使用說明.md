# 使用說明

## 我只想看進度（大部分同事）

打開試算表，點下方的 **「包裝備料清單」** 分頁。

| 燈號 | 意思 |
|---|---|
| 🔴 現在備 | 這個時段就要把包材備好 |
| 🔴 逾期 | 已經超過該備好的時間，趕快處理 |
| 🟡 下時段備 | 下一個時段要備 |
| 🟢 已備料 | 包材已經備好 |
| ⚪ 還早 | 還不用處理 |

- 清單依「包裝開始」時間排好，**越上面越早要包裝**
- 出貨日變成**紅色**：預計包裝完成時間已經晚於出貨日，請通知生管
- 想看整體時間軸：點 **「甘特圖」** 分頁

## 手機上勾選「已備料」

1. 手機安裝「Google 試算表」App，打開這份檔案
2. 點「包裝備料清單」分頁
3. 包材備好了，就勾選該工單的 **「已備料」**
4. 等 1～3 秒，燈號就會變成 🟢

## 排程人員：每天要做的事

所有修改都在 **「工單排程」** 分頁。

### 新增工單
在最下面的空白列填：工單編號、品名、出貨日、目前狀態、**包裝順序**、**包裝時段數**。

- 包裝時段數：上午、下午、加班各算 1 個時段，半個時段填 `0.5`
- 還不知道什麼時候包裝：**包裝順序先空白**，會顯示「未排入」

### 工單開始包裝
把「目前狀態」改成 **包裝中**，系統會自動記下開始的時間。

### 工單包裝完成
把「目前狀態」改成 **完成**，下一張工單會自動接上。

### 外包品回廠要插隊
把它的「包裝順序」填在兩張工單中間，例如要插在第 2 和第 3 張之間就填 `2.5`。後面的工單會**全部自動往後順延**。

> 小技巧：順序用到很多小數時，可以找個空檔把順序重新編成 1、2、3……

### 知道外包品大概幾點回廠
在「指定開始日」和「指定開始時段」填最早能包裝的時間，系統就不會把它排在這之前。

### 原本擱置的工單
狀態改成 **待包裝**，甘特圖上會顯示灰色的等待區段。

## 放假、颱風、加班變動

打開 **「工作日曆」** 分頁，找到那一天：

| 狀況 | 怎麼改 |
|---|---|
| 國定假日不上班 | 取消勾選上午、下午、晚上加班、備料人員上班 |
| 國定假日要加班 | 只勾上午、下午（備料人員上班不勾） |
| 颱風天停工 | 全部取消勾選 |
| 某天晚上不加班 | 取消勾選「晚上加班」 |
| 週六補班 | 勾選「晚上加班」和「備料人員上班」 |

改完之後，排程和最晚備料時間會自動重算。

## 常見問題

**Q：「工單排程」右邊灰色的欄位為什麼不能改？**
那四欄是自動計算的，鎖起來是為了避免不小心改壞。

**Q：燈號沒有更新？**
修改後通常 1～3 秒就會更新；另外每 30 分鐘也會自動更新一次。試算表擁有者可以按上方選單「📦 排程工具 → 立即更新」。

**Q：出現「⚠ 缺時段數」？**
有填包裝順序，但沒填包裝時段數。

**Q：出現「⚠ 工單重複」？**
有兩列的工單編號一樣，請檢查是不是重複輸入。

**Q：時段的時間跟我們公司不一樣？**
到「選項設定」修改上午、下午、加班的開始和結束時間（限擁有者）。
