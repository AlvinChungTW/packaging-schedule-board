# 使用說明

## 我只想看進度（大部分同事）

打開試算表，點下方的 **「包裝備料清單」** 分頁。

| 燈號 | 意思 |
|---|---|
| 🔴 現在備 | 這個時段就要把包材備好 |
| 🔴 逾期 | 已經超過該備好的時間，趕快處理 |
| 🟡 下時段備 | 下一個時段要備 |
| 🟢 已備料 | 包材已經備好 |
| ⚪ 還早 | 還不用處理 |

- 清單依「包裝開始」時間排好，**越上面越早要包裝**
- 出貨日變成**紅色**：預計包裝完成時間已經晚於出貨日，請通知生管
- 想看整體時間軸：點 **「甘特圖」** 分頁

## 手機上勾選「已備料」

1. 手機安裝「Google 試算表」App，打開這份檔案
2. 點「包裝備料清單」分頁
3. 包材備好了，就勾選該工單的 **「已備料」**
4. 等 1～3 秒，燈號就會變成 🟢

## 主管：新增工單（電腦版）

1. 用電腦打開試算表，點 **「工單排程」** 或 **「包裝備料清單」** 頂端的藍色按鍵 **「＋ 新增工單」**
   （也可以從上方選單「📦 排程工具 → ＋ 新增工單」打開）
2. 依序選 **客戶** → **機型**，機型選單只會出現這個客戶的機型
3. 填 **工單編號**、**數量**，其他欄位有資料再填
4. 按 **「新增工單」**
5. 出現綠色的「已新增工單」就完成了。視窗會保留客戶、機型和日期，可以接著輸入同一張訂單的下一批工單
6. 全部輸入完，按 **「關閉」**

| 視窗裡的選項 | 說明 |
|---|---|
| 包裝排程：排到最後 | 預設選項，排在目前所有工單的後面 |
| 包裝排程：先不排入 | 還不知道什麼時候包裝 |
| 包裝排程：指定順序 | 要插隊時使用，例如填 `2.5` |
| 包裝時段數 | 選好機型、填好數量後會自動算出來，也可以自己改 |

> 手機 App 不能使用新增工單按鍵，請用電腦操作。

## 排程人員：每天要做的事

所有修改都在 **「工單排程」** 分頁。

### 新增工單
可以用上面的「＋ 新增工單」視窗，也可以直接在最下面的空白列填寫：工單編號、客戶、機型（都是下拉選單）、數量、出貨日、目前狀態、**包裝順序**。

- **包裝時段數可以留空**：系統會用「數量 ÷ 機型每時段包裝數量」自動算，儲存格右上角會有「自動計算」的註解
- 要自己決定時段數，直接填數字就好（上午、下午、加班各算 1 個時段，半個時段填 `0.5`）；清空就會恢復自動計算
- 還不知道什麼時候包裝：**包裝順序先空白**，會顯示「未排入」

### 工單開始包裝
把「目前狀態」改成 **包裝中**，系統會自動記下開始的時間。

### 工單包裝完成
把「目前狀態」改成 **完成**，下一張工單會自動接上。

### 外包品回廠要插隊
把它的「包裝順序」填在兩張工單中間，例如要插在第 2 和第 3 張之間就填 `2.5`。後面的工單會**全部自動往後順延**。

> 小技巧：順序用到很多小數時，可以找個空檔把順序重新編成 1、2、3……

### 知道外包品大概幾點回廠
在「指定開始日」和「指定開始時段」填最早能包裝的時間，系統就不會把它排在這之前。

### 原本擱置的工單
狀態改成 **待包裝**，甘特圖上會顯示灰色的等待區段。

## 放假、颱風、加班變動

打開 **「工作日曆」** 分頁，找到那一天：

| 狀況 | 怎麼改 |
|---|---|
| 國定假日不上班 | 取消勾選上午、下午、晚上加班、備料人員上班 |
| 國定假日要加班 | 只勾上午、下午（備料人員上班不勾） |
| 颱風天停工 | 全部取消勾選 |
| 某天晚上不加班 | 取消勾選「晚上加班」 |
| 週六補班 | 勾選「晚上加班」和「備料人員上班」 |

改完之後，排程和最晚備料時間會自動重算。

## 新客戶、新機型

| 要做的事 | 到哪裡改 |
|---|---|
| 新增客戶 | 「客戶清單」分頁，在最下面填客戶名稱 |
| 新增機型 | 「機型清單」分頁，先選客戶，再填機型 |
| 設定機型每個時段可以包裝幾台 | 「機型清單」的「每時段包裝數量」 |

新增後，工單排程和新增工單視窗的選單會自動出現新的選項。

> 已經在用的客戶名稱、機型名稱，請不要直接改名，否則舊工單會對不上。

## 常見問題

**Q：改「工單排程」右邊灰色欄位時跳出警告？**
那四欄是自動計算的，不需要手動改，請按「取消」。就算不小心改到，下次更新也會自動改回正確的值。

**Q：機型選單裡找不到要的機型？**
先確認「客戶」選對了，機型選單只會列出該客戶的機型。如果是新機型，請到「機型清單」新增。

**Q：燈號沒有更新？**
修改後通常 1～3 秒就會更新；另外每 30 分鐘也會自動更新一次。用電腦也可以按上方選單「📦 排程工具 → 立即更新」。

**Q：出現「⚠ 缺時段數」？**
有填包裝順序，但沒填包裝時段數。

**Q：出現「⚠ 工單重複」？**
有兩列的工單編號一樣，請檢查是不是重複輸入。

**Q：時段的時間跟我們公司不一樣？**
到「選項設定」修改上午、下午、加班的開始和結束時間（限擁有者）。
