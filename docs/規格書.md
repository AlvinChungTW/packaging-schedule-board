# 包裝備料排程工具：規格書 v1.1

| 版本 | 內容 |
|---|---|
| v1 | 排隊制排程、備料期限、燈號、甘特圖、工作日曆 |
| v1.1 | 新增工單視窗、客戶清單、機型清單、依機型自動算包裝時段數；自動區域改為「修改前警告」 |

## 1. 背景與目標

| 項目 | 說明 |
|---|---|
| 使用者 | 包裝備料人員（主要）、生管與產線主管、同事（查閱） |
| 痛點 | 原本的表格只有預計出貨日，看不出排程；排程常變動，難以掌握包裝時間 |
| 目標 | 一眼看出每張工單何時進入包裝、包材最晚何時要備好 |
| 平台 | Google 試算表 + Google Apps Script（公司使用 Google 帳號） |
| 原則 | 操作越簡單越好；非必要的功能省略，保留擴充空間 |

## 2. 業務規則

### 2.1 工作階段
組裝 → 測試 → 包裝，三個階段不重疊。部分組裝外包，外包品回廠後可能插隊進包裝，原本已組裝好的工單就先擱置（狀態「待包裝」）。

### 2.2 追蹤單位
**工單**。一張工單只有一種產品；同一張訂單分批包裝，就拆成多張工單。

### 2.3 時段

| 日期 | 產線時段 | 備料人員 |
|---|---|---|
| 週一～五 | 上午、下午、晚上加班 | 上午、下午 |
| 週六 | 上午、下午 | 不上班 |
| 週日 | 休息 | 不上班 |
| 國定假日 | 依需求加班（在工作日曆勾選） | 不上班 |

每個時段可以再分前半、後半，排程的最小單位是半個時段。

### 2.4 排程方式：排隊制
包裝線同一時間只做一張工單。

- 依「包裝順序」由小到大排，每張工單的開始時間 = 前一張的結束時間
- 遇到沒上班的時段（週日、取消加班、停工）自動跳過
- 狀態「完成」的工單離開隊伍
- 「指定開始」：
  - 狀態為「包裝中」：視為實際開始時間，隊伍以它為起點（沒填時系統自動記下現在的時段）
  - 其他狀態：視為最早可以開始的時間（例如外包品回廠時間）
- 第一張還沒開始的工單，從「現在」的時段開始排
- 插隊：順序填小數，例如 `1.5`

### 2.5 組裝、測試
只記「目前狀態」和「預計完成日」（以天為單位，可以不填），甘特圖上以整天顯示。

### 2.6 最晚備料時間
包裝開始時段**之前**，備料人員的最後一個上班時段：

| 包裝開始 | 最晚備好 |
|---|---|
| 平日下午 | 當天上午 |
| 平日晚上加班 | 當天下午 |
| 平日上午 | 前一個上班日下午 |
| 週六／假日 | 假日前最後一個上班日下午 |

### 2.7 燈號
以「備料人員時段」計算現在到最晚備料時間還有幾個時段：

| 燈號 | 條件 |
|---|---|
| 🔴 逾期 | 已經超過最晚備料時段，還沒備料 |
| 🔴 現在備 | 目前（或下一個上班時段）就是最晚備料時段 |
| 🟡 下時段備 | 再過「黃燈提前時段數」以內（預設 1） |
| ⚪ 還早 | 其他 |
| 🟢 已備料 | 已勾選已備料 |
| ✔ 完成 | 狀態為完成 |
| － 未排入 | 沒有包裝順序 |
| ⚠ 缺時段數／超出日曆／工單重複 | 資料有問題 |

晚上加班或假日查看時，「目前」指的是備料人員下一個上班時段。

### 2.8 現場包材數
甘特圖最下方一列。每個時段計算：已備料、或已到最晚備料時段，而且還沒包裝完的工單數。

### 2.9 出貨風險
預計包裝結束日晚於出貨日時，在包裝備料清單把出貨日標紅。

### 2.10 包裝時段數自動計算
- 公式：數量 ÷ 機型的「每時段包裝數量」，以 0.5 時段無條件進位（最少 0.5）
- 包裝時段數**空白**時自動計算，儲存格會加上「自動計算」註解；之後數量或每時段包裝數量改變，會跟著重算
- 直接輸入數字就變成手動值，不再自動重算；清空則恢復自動
- 機型沒有設定每時段包裝數量時，需要手動填寫

## 3. 工作表

### ① 工單排程

| 欄 | 名稱 | 輸入方式 | 備註 |
|---|---|---|---|
| A | 訂單編號 | 文字 | |
| B | 工單編號 | 文字 | 必填，不可重複 |
| C | 客戶 | 下拉（客戶清單） | |
| D | 機型 | 下拉（只列出該客戶的機型） | 取代 v1 的「品名」 |
| E | 數量 | 數字 1～100000 | |
| F | 出貨日 | 日期 | |
| G | 組裝方式 | 下拉：自製／外包 | |
| H | 目前狀態 | 下拉 | 未開工、組裝中、外包中、測試中、待包裝、包裝中、完成 |
| I | 組裝預計完成日 | 日期 | |
| J | 測試預計完成日 | 日期 | |
| K | 包裝順序 | 數字 | 可用小數插隊；空白 = 未排入 |
| L | 包裝時段數 | 數字 | 0.5 為單位；空白時自動計算（見 2.10） |
| M | 指定開始日 | 日期 | 選填 |
| N | 指定開始時段 | 下拉 | 上午、上午後半、下午、下午後半、加班、加班後半 |
| O | 已備料 | 勾選框 | |
| P | 備註 | 文字 | |
| Q～T | 包裝開始、包裝結束、最晚備料、燈號 | 自動 | 修改前警告；每次更新重算 |

第 1 列標題上方有「＋ 新增工單」按鍵。

### ② 工作日曆
日期、星期、上午、下午、晚上加班、備料人員上班（勾選框）、備註。自動延長到今天之後 120 天，並依星期套用預設值。

### ③ 包裝備料清單
燈號、已備料（可勾選，會同步回 ①）、工單編號、包裝開始、最晚備料、客戶、機型、數量、狀態、訂單編號、出貨日。依包裝開始時間排序，未排入的放最後；第 1 列是摘要和「＋ 新增工單」按鍵。前五欄設計成手機直式畫面也看得到。

### ④ 甘特圖
從現在所在的那天起 14 天（可調整），每欄是半個時段，不上班的日期不顯示。

| 顏色 | 意義 |
|---|---|
| 藍 | 組裝（自製） |
| 紫 | 組裝（外包） |
| 黃 | 測試 |
| 灰 | 待包裝（擱置中） |
| 綠 | 包裝；深綠 = 包裝中 |
| 紅字「備」 | 最晚備料時段 |
| 橘色標題 | 現在時段 |

### ⑤ 客戶清單、機型清單

| 工作表 | 欄位 |
|---|---|
| 客戶清單 | 客戶名稱、備註 |
| 機型清單 | 客戶名稱（下拉）、機型、每時段包裝數量（選填，> 0）、備註 |

每個機型屬於一個客戶。修改這兩張表後，① 的機型選單和自動時段數會跟著更新。

### ⑥ 選項設定
上午、下午、加班的開始與結束時間（只用來判斷「現在」是哪個時段）、黃燈提前時段數、甘特圖天數、日曆保留天數，以及下拉選單清單。

## 4. 新增工單視窗

**開啟方式**：① 和 ③ 頂端的「＋ 新增工單」按鍵，或選單「📦 排程工具 → ＋ 新增工單」。**只能在電腦版瀏覽器使用**，Google 試算表手機 App 不支援自訂按鍵與視窗。

| 欄位 | 規則 |
|---|---|
| 客戶 \* | 從客戶清單選 |
| 機型 \* | 選了客戶後，只列出該客戶的機型 |
| 工單編號 \* | 最多 30 字；輸入時就會提示是否重複（不分大小寫） |
| 訂單編號 | 最多 30 字 |
| 數量 \* | 1～100000 的整數 |
| 出貨日、組裝預計完成日、測試預計完成日 | 日期選擇器 |
| 組裝方式、目前狀態 | 下拉；狀態預設「未開工」 |
| 包裝排程 | 排到最後（預設，未完成工單最大順序取整數 + 1）／先不排入／指定順序 |
| 包裝時段數 | 依機型自動帶入，可以手動改；要排入包裝時必填 |
| 備註 | 最多 200 字 |

- 送出後在伺服器端重新驗證；有錯誤時列出原因，不會寫入
- 成功後寫在 ① 最後一筆工單的下一列，並立即重算排程
- 視窗不會關閉，保留客戶、機型、日期，方便連續輸入同一張訂單的多張工單

## 5. 自動更新
- 任何人編輯 ①②③⑤⑥ 後，可安裝的編輯觸發器會以擁有者身分重算（約 1～3 秒）
- 用新增工單視窗新增後，立即以操作者身分重算
- 每 30 分鐘自動更新一次燈號，並延長工作日曆
- 選單「📦 排程工具 → 立即更新」

## 6. 權限與資安
- 共用設定「限公司網域」，依人分別給編輯者或檢視者
- ① 的自動欄位、③ 包裝備料清單、④ 甘特圖：**修改前警告**。這些內容每次更新都會整個重算，就算誤改也會被蓋回；也讓主管用視窗新增工單後能立即重算
- ② 工作日曆、⑥ 選項設定：只有擁有者能改
- ③ 的「已備料」欄不設保護，勾選不會跳警告
- 新增工單的輸入一律在伺服器端驗證；文字開頭是 `= + - @` 時加上 `'`，避免公式注入；視窗畫面用 `textContent` 顯示資料
- 範例資料與本專案原始碼不包含任何真實公司、客戶或工單資料

## 7. 預留擴充
| 項目 | 擴充方式 |
|---|---|
| 前置排程（訂單啟動、物料進貨） | 在 ① 加日期欄，甘特圖加對應顏色 |
| 材料清單 | 新增工作表，以機型對應包材，工單依機型與數量自動帶出用量 |
| ERP 匯入 | 新增「匯入區」工作表，貼上 ERP 匯出的工單資料後對應到 ① |
| 階段完成簽核 | 在 ① 加「確認人／確認時間」欄位 |
